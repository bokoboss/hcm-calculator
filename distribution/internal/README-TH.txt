HCM Calculator รุ่น 0.9.0
แพ็กเกจ Portable สำหรับใช้ภายในบริษัทบน Windows x64

วิธีใช้งาน
1. รองรับ Windows 10/11 แบบ 64-bit (x64)
2. แตกไฟล์ ZIP ให้เรียบร้อยก่อนใช้งาน ห้ามเปิดโปรแกรมจากภายใน ZIP
3. ดับเบิลคลิกไฟล์ Run HCM Calculator.bat
4. โปรแกรมจะเปิด browser ที่ http://127.0.0.1:8765/ โดยอัตโนมัติ
5. หาก browser ไม่เปิด ให้เปิดที่อยู่ http://127.0.0.1:8765/ ด้วยตนเอง
6. วิธีหยุดโปรแกรม: กด Ctrl+C หรือปิดหน้าต่าง console

ข้อกำหนด
- ไม่ต้องติดตั้ง Python หรือ Node
- หลังจากได้รับและแตกแพ็กเกจแล้ว ไม่ต้องใช้อินเทอร์เน็ต
- ไม่ต้องใช้สิทธิ์ Administrator
- แนะนำให้เก็บไฟล์ Project JSON, Excel, CSV และรายงานไว้นอกโฟลเดอร์โปรแกรม

กรณี Windows Defender, AppLocker, EDR หรือระบบความปลอดภัยของบริษัทบล็อกการทำงาน
โปรดติดต่อ IT ของบริษัทเพื่อขอคำแนะนำ ห้ามปิดหรือหลีกเลี่ยง security control
